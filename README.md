## 👋 About Me

I'm a **software architect and full-stack engineer** based in Islamabad, Pakistan, with 11+ years of experience designing and shipping web and mobile products, from real-time messaging platforms to AI-assisted data products.

I enjoy turning messy, fragmented problems into clean systems: well-structured APIs, reliable data pipelines, and fast, polished interfaces.

- 🔭 Currently building **web and mobile applications** across the React / Node ecosystem
- 🏗️ Focused on **system design, scalable backends, and developer experience**
- 🤖 Exploring **AI-assisted workflows** and agentic tooling (certified in *Claude Code in Action* and the *Google AI Professional Certificate*)
- 🌍 Open to remote roles and **relocation**
- 🤝 Open source enthusiast, always happy to collaborate
- 💬 Ask me about: **React, React Native, Node.js, TypeScript, system architecture, Supabase, Laravel**
